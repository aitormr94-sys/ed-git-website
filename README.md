# ed-git-website

Website for **Brisa Surf School**, a fictional surf school on the Mediterranean coast. It offers group and private surf lessons and board rental from June to September.

This repository is assignment 4.T1 of the _Entornos de Desarrollo_ module. It is used to practise Git and GitHub: commits, `.gitignore`, branches, merges, conflicts, tags and GitHub Pages.

## Technologies

- HTML
- CSS

## How to open the website

1. Clone the repository:
   ```bash
   git clone https://github.com/aitormr94-sys/ed-git-website.git
   ```
2. Open the `ed-git-website` folder.
3. Double-click `index.html`, or right-click it and choose _Open with_ and your browser.
